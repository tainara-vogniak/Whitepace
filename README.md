Este projeto é um site fictício de uma empresa, desenvolvido para fins de **prática em desenvolvimento web** e **portfólio**. A proposta foi criar um layout moderno, com navegação funcional entre páginas, usando apenas tecnologias front-end.

## 🔎 Sobre o projeto

O site conta com:

- Página inicial apresentando a empresa
- Menu de navegação fixo e responsivo
- Páginas adicionais com informações sobre serviços, contato e mais
- Layout bonito, limpo e adaptável a diferentes tamanhos de tela

## 🛠 Tecnologias utilizadas

- **HTML5**
- **CSS3**
- **JavaScript (puro)**

## 📁 Estrutura de páginas

- `index.html` – Página inicial
- `servicos.html` – Página de serviços
- `contato.html` – Página de contato
- `sobre.html` – Sobre a empresa (opcional)
- `style.css` – Estilização geral
- `script.js` – Funcionalidades básicas (ex: menu responsivo)
